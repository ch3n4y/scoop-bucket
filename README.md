# scoop-bucket

My personal [Scoop](https://scoop.sh) bucket.

## Install

```powershell
scoop bucket add ch3n4y https://github.com/ch3n4y/scoop-bucket
```

## Packages

| Package | Description |
| --- | --- |
| `pail` | Desktop client for S3-compatible object storage |
| `easytier-manager` | EasyTier desktop manager |
| `aisafetest` | AgSec agent security evaluation platform |
| `wifit3` | USB Wi-Fi auditor |

```powershell
scoop install ch3n4y/<package>
```

For example:

```powershell
scoop install ch3n4y/pail
```

## Update

```powershell
scoop update
```
